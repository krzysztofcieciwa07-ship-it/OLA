# OLA Integrity Layer — Product Scope

The active product decision authority is [OLA Integrity Layer — Decision Charter v1.0](OLA_INTEGRITY_LAYER_DECISION_CHARTER_v1.0.md).

**MVP:** OLA DORA Audit Evidence Pack for one ICT change-management process.  
**North Star:** shorten the path from a software change to an auditable, independently verifiable evidence package.

The first 60-day non-goals are a graph database, dashboard, AI Auditor, additional regulatory packs, marketplace, multi-tenant platform and new generic runtime/gateway. Any exception must pass the charter's H1–H4 decision filter.

The DORA pack is a draft/pilot-validation artefact. It does not certify an organisation, provide legal advice, prove full DORA compliance or guarantee auditor acceptance.
