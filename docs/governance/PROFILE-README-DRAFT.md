# Building OLA

Building evidence-driven AI execution and verification systems.

## Focus

- Controlled AI-agent execution and human approval boundaries.
- Tenant-scoped evidence, provenance and replayable verification.
- Security engineering and software supply-chain integrity.
- SRE/DevOps incident-response exercises and recovery evidence.

## Engineering principles

- Unknown is not verified.
- Every release is bound to an exact source commit and artifact digest.
- High-risk actions require an explicit human authorisation boundary.
- Evidence integrity, provenance and confidentiality are separate controls.
- Security claims are limited to tests and assessments that actually ran.

## Security and assurance status

The projects are undergoing governance and security hardening. CyFun 2025 Essential is being used as an engineering target for control mapping. This profile does not claim CCB certification, NIS2 compliance, independent certification or production readiness.
